## 概要

ソフトウェア開発者・writer。Google と Microsoft で開発者として勤務した経歴を持ち、現在は[個人プロジェクト](https://mtlynch.io/projects/)を運営。技術記事サイト [Refactoring English](https://refactoringenglish.com/)("Effective writing for software developers")の著者で、本人ハンドルは `@deliberatecoder`、メール `michael@refactoringenglish.com`。

## 主な公開物

- **[[design-doc]] の書き方の記事**: "How to Write an Effective Software Design Document"(2026-06-24)。Google/Microsoft での design doc 執筆経験から、書くべき決定の判断軸(間違えたときのコスト)と 23 個の構成要素を整理。
- **公開 design doc 実例**: 自作 OSS [`little-moments`](https://codeberg.org/mtlynch/little-moments)(個人 web アプリ)について[実物の design doc](https://refactoringenglish.com/excerpts/write-an-effective-design-doc/little-moments-design-doc/) を公開。コードを書く前に設計を確定し、実装はその設計に沿って進める運用。本人いわく「世に出ている high-quality な design doc を見たことがないので自分で書いた」。
