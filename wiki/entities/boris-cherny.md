## 概要
**Boris Cherny(ボリス・チェルニー)** は、当該記事中で **Anthropic の Claude Code 責任者(head of Claude Code at Anthropic)** と紹介される人物。[[loop-engineering]](ループエンジニアリング)の議論で [[peter-steinberger]] と並ぶ起点の発言者として、[[addy-osmani]] のブログ記事 "Loop Engineering"(2026-06-07)に出典付きで引用される。本 wiki には Osmani の記事経由で登場する。

> ⚠️ 出典の範囲: 本ページの記述は ingest 済みの "Loop Engineering" 1本に基づく。肩書「head of Claude Code at Anthropic」は当該記事に明記された範囲。それ以外の経歴・伝記情報は記事に含まれないため未収録(推測で補わない)。

## 詳細

### 引用された発言
[[addy-osmani]] は [[peter-steinberger]] の発言に続けて、Cherny の次の言葉を loop engineering のもう一つの起点として引用している:

> "I don't prompt Claude anymore. I have loops running that prompt Claude and figuring out what to do. My job is to write loops."
> (私はもう Claude に prompt しない。Claude に prompt し何をすべきか考える**ループを走らせている**。私の仕事はループを書くことだ。)

### 記事内での位置づけ
- 記事の結論部で Osmani は「**Cherny's point** は『仕事が楽になった』ではなく『**leverage point(梃子の支点)が動いた**』ことだ」と述べ、loop engineering が「楽になる話」ではなく「テコの効かせどころが prompt からループ設計へ移った話」であることの論拠として Cherny を引いている。
- これは「loop design は prompt engineering より易しくなく、むしろ難しい」という記事の主張([[loop-engineering]] 参照)を支える核の一つ。
