## 概要

TypeScript educator / AI エンジニアリング教育者。Total TypeScript の作者、XState core team 出身、元 Vercel developer advocate。現在は **AI Hero**(`aihero.dev`)を運営し、Claude Code 向けの実践的なエージェントスキル("AI Skills for Real Engineers")を公開している(推測: 経歴は Web 検索結果に基づく)。
