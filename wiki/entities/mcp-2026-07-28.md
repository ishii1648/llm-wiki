## 概要
**MCP 2026-07-28** は [[model-context-protocol]](MCP)の第5版スペックリリース(2026-07-28 公開)。プロトコルコアを **stateless(request/response モデル)** に移行し、認可(authorization)を OAuth 2.0 / OIDC の本番運用に整合させ、MCP Apps / Tasks を versioned な拡張フレームワークへ正式昇格させた([[mcp-extensions]])。Anthropic は「最も重要なスペックリリースの一つ」と位置づけ、Claude 製品群へ順次サポートを展開中。

## 詳細

### 3つの柱
1. **Stateless core**: 双方向のステートフルプロトコルから request/response モデルへ移行。MCP サーバを serverless / edge インフラに配備できるようになり、サーバ構築とスケーリングが単純化される。
2. **Standardized extensions**: MCP Apps(対話的 UI)と Tasks(長時間処理)が versioned extensions framework の下で提供され、コアプロトコルを変更せずに能力を追加する正式な経路ができた。詳細は [[mcp-extensions]]。
3. **Auth hardening**: 認可が本番の OAuth 2.0 / OIDC デプロイメントに整合し、Entra や Okta のようなエンタープライズ ID システムへ回避策なしで接続できる。

### 普及状況
- MCP の月間 SDK ダウンロードは **4億(400M)超**、今年 4 倍に増加。「AI エージェントをアプリケーションに接続する業界標準」となった。
- Claude の connectors directory には **950 超の MCP サーバ**が掲載され、毎日数百万人が利用。
- ベータ期間から Figma・Intuit・Netlify・PostHog・Xero・Zoom などが新スペック上で構築。各社の評価の要点:
  - **Netlify**(Sean Roberts): stateless core により MCP が「セッション管理の回避策が不要な first-class の HTTP ワークロード」になった。
  - **PostHog**(Paul D'Ambra): stateless 化で自社サービスのスケールと顧客 MCP サーバの分析提供が容易になる。
  - **Figma**(Josh Clemm): stateless アーキテクチャで利用増に追従でき、Apps/Tasks/Enterprise-Managed Auth でデザインとコードを一つのフローに保てる。
  - **Zoom**(Ross Mayfield): 標準 HTTP インフラ上での MCP サーバのデプロイ・スケールが大幅に容易になった。

### Claude 側の関連機能(2026年に出荷)
スペック対応と並行して、Claude プラットフォームは MCP の構築・配備を容易にする機能を出荷している:
- **MCP Apps**: サーバが会話内に対話的 UI を直接レンダリングする([[mcp-extensions]])。
- **Enterprise-managed auth**: 管理者が IdP 経由で組織全体に connector をプロビジョニング。一度認可すればユーザーは既存 IdP グループ経由でアクセスを継承し、初回ログインで接続済み(ゼロタッチ)。
- **Observability for developers**: directory 掲載 connector に、Claude 製品面ごとのパフォーマンス・採用状況・エラー/レイテンシを示すダッシュボードを提供。
- **MCP tunnels(research preview)**: プライベートネットワーク内の MCP サーバへ、公開エンドポイント・inbound firewall ルール・IP allowlist なしで Claude から接続。
